## 🌟 项目简介

**dayroom** 是一个集 **深度 AI 对话创作、沉浸式角色卡工作台、全网无损音乐电台、Live2D 陪伴萌宠、Web Audio 程序化声音空间、实用生产力工具箱与动态沉浸氛围壁纸** 于一体的高美感单页 Web 应用。

无论你是想要专注码字创作、与细腻生动的拟人角色畅聊、搭建属于自己的二次元角色卡世界，还是在清雅的背景乐、真实物理微动效与桌面小宠的陪伴下高效学习工作，dayroom 都能为你提供兼具实用价值与视觉享受的数字栖息空间。

### 1. 💬 智能 AI 对话与创意空间
- **双大模型智能路由**：
  - **DeepSeek V4.1**：默认高能引擎，支持**原生多模态视觉看图**（直接发送图片解析）与**原生 Responses 服务端联网检索**（实时资讯精准解答）。
  - **Google Gemini 3.6 Flash**：支持在角色设置中一键按需切换，体验多元化思考风格。
- **4 大内置拟人化角色**：各具独特语气与长驻 Prompt（周图、小说助理、AI写作助手、TODO 效率助手）。
- **无限制创作模式（锁屏鉴权）**：输入管理密钥解锁，解除常规对话长度限制，支持长达几十万字的长篇小说深潜连载。
- **对话全量归档**：基于本地浏览器 `IndexedDB` 独立持久化归档，安全无泄露。

### 2. 🎴 角色卡工作台 v2 (Rolecard Workbench)
- **纯前端 CCv3 / PNG 角色卡无损导入**：
  - 支持 Tavern / Chub 标准角色卡格式，自动提取并清洗 PNG `tEXt` 块中的 Base64 元数据（兼容 `chara` 与 `ccv3` 规范）。
- **两级沉浸式视图**：
  - **画廊视图**：角色卡瀑布流卡片展示，支持搜索、R18 标签切换与卡片管理。
  - **全屏聊天视图**：微拟物对话气泡、沉浸式背景与双向宏变量替换（`{{user}}` / `{{char}}`）。
- **动态状态面板（HUD）**：
  - 角色对话末尾输出 `【状态面板】{JSON}` 自动剥离并解析为生命值、好感度、理智值、情绪状态等进度条。
  - 状态实时回传下一轮 Prompt，实现游戏级互动养成。
- **预置高质量卡片**：内置预置角色卡（如黑长直冷艳同桌·苏璃 `rc_suri` 等）。

### 3. 🎵 音乐休闲电台 (Music Station)
- **酷我官方全网原生引擎**：
  - 后端直接对接酷我官方搜索与高防 CDN 直连解析，秒出音频流，免登录、免 VIP 限制、全球流畅直连。
- **双音源互斥播放引擎**：
  - **放松频道**：精选 Lo-fi、纯音乐钢琴、助眠雨声、沉浸氛围等 12 组高清电台。
  - **搜索点歌**：支持歌名、歌手全网模糊搜索，一键试听、加入播放列表。
  - **互斥守护**：切换频道、切歌或模式切换时，自动静默暂停另一音源，杜绝双声重叠。
- **3 态播放模式 & 双音量联动**：
  - 支持 `🔁 列表循环`、`🔂 单曲循环`、`🔀 随机播放`（Fisher-Yates 算法），自动记忆持久化。
  - 双模式音量控制条双向联动，支持一键静音/还原。
- **实时动效**：Canvas 音频频谱跳动波形与 Bilibili 视屏伴奏抽屉。

### 4. 🐾 桌面常驻 Live2D 萌宠 (Desktop Companion)
- **昼夜环境自适应**：
  - 随网站 Day / Night 主题联动：**夜晚陪伴·黑猫 Hijiki** (Model 0) ↔ **晨曦元气·柴犬 Wanko** (Model 1)。
  - 接入平滑淡出微缩放动效，告别生硬突兀跳变。
  - 支持鼠标长按自由贴底拖拽位置。
- **全新悬浮毛玻璃 Capsule Dock（6 大交互功能）**：
  - 💬 **倾听一言**：拉取治愈、哲思名句并在气泡分段展示出处与作者。
  - 💖 **摸摸治愈**：触发 Live2D 专属动作，猫咪发出舒适呼噜踩奶、柴犬欢快摇尾贴贴。
  - 🍵 **贴心管家**：针对久坐办公，随机提醒温水补水、脊椎放松、远眺护眼、伸展懒腰与能量补充。
  - 🐾 **切换萌宠**：生动爪印图标，一键手动在黑猫与柴犬间热切换。
  - 🎮 **摸鱼游戏**：现代手柄图标，一键拉起全屏经典贪吃蛇小游戏。
  - ✕ **宠物休息**：温柔道别并淡出，左下角留存唤醒按钮随时召唤。
- **纯 CSS 悬浮微气泡 Tooltip**：悬浮向外优雅展示气泡，不遮挡宠物本身，完美适配白天模式。

### 5. 🎧 声音空间 (Sound Space · 微动效与白噪音混音台)
- **100% 纯数学计算与无损合成**：
  - 拒绝加载笨重的 `.mp3` / `.wav` 外部音频文件，底层纯粹利用浏览器原生 **Web Audio API** 实时数学合成与滤波。
  - 杜绝录音循环播放产生的“接缝机械感”，呈现一条永不重复的有机自然声场河流；手机端自动隐藏，桌面端专属沉浸。
- **开机通电仪式感与拟物微缩入口**：
  - 默认状态完全静默，遵从现代浏览器手势激活策略；
  - 顶部微型毛玻璃波形指示条与拨动开关，点击通电瞬间触发类似老式胆机音箱通电的轻微机械拨片脆响与温热低频底噪（58Hz / 116Hz 谐波）。
- **专业级声学可视化视窗（实时双层 Canvas 示波器）**：
  - **时域合成波形 & 有机颗粒 (Time-Domain Waveform)**：实时抓取音频振幅绘制平滑示波器曲线，当触发有机脉冲或水滴时激荡出动态漂浮粒子与涟漪波纹；
  - **对数频谱能量 & 低通截止包络 (Log Spectrum & Cutoff Envelope)**：32 根三色对数分频柱状频谱（浅蓝/绿/暖金），配合动态滑动 Cutoff 截止线（$16,000\text{Hz} \leftrightarrow 360\text{Hz}$）与指数衰减虚线包络。
- **5 组精心调校的治愈配方推荐（Curated Presets）**：
  - 🌧️ **深夜雨窗**（潮汐 70% · 颗粒 65% · 垫音 20%）
  - 🪵 **壁炉夜话**（潮汐 35% · 颗粒 45% · 垫音 40%）
  - 🚀 **太空漫游**（潮汐 20% · 颗粒 10% · 垫音 75%）
  - 🌊 **海岸退潮**（潮汐 85% · 颗粒 20% · 垫音 30%）
  - ☕ **极简专注**（潮汐 50% · 颗粒 15% · 垫音 35%）
  - 一键平滑指数插值变奏（$\tau = 220\text{ms}$，杜绝爆音与突变）。
- **第一层声场：微交互音效（赋予网页物理触感）**：
  - **防疲劳“微随机”悬停**：鼠标划过功能按钮时，激发 5~15ms 短促微粒子，基频以 1380Hz 为中心在 ±4% 范围内微随机浮动，告别生硬机械报警音；
  - **双阶段按压感**：点击按钮时，860Hz 清脆下压触底瞬态声 + 28ms 延迟 440Hz 闷声回弹尾音，还原高端微动开关段落感；
  - **昼夜声学窗帘**：Day/Night 主题切换时，低通滤波器在 0.4s 内扫频展开或收拢，如拉上厚重天鹅绒窗帘。
- **第二层声场：三轨程序化环境混音台**：
  - 🌊 **暖色基底 (Warm Tide)**：布朗噪音（Brown Noise）+ 0.087Hz 超低频振荡器（LFO）起伏滤波，模拟远方夜雨与海岸潮汐呼吸；
  - 🔥 **有机颗粒 (Organic Crackle)**：基于泊松分布随机脉冲生成器，左推为冬夜壁炉柴火噼啪，右推为打在树叶窗棱的清脆雨点；
  - 🌌 **漂移垫音 (Ambient Drone)**：微调偏音（Detuned）的三正弦波，锁定在大七度悬留和弦，穿过长尾滤波填补空间空旷感。
- **第三层点睛：空间联觉与“隔壁房间”效应**：
  - **Tab-Blur 失焦衰减**：切换标签页或窗口失焦时，微交互音效自动休眠，混音台总输出滤波器在 1.5 秒内平滑沉降至 360Hz（仅保留温暖低频），模拟起身虚掩房门走到隔壁书房的沉浸听感；切回时 1 秒内温柔敞开；
  - **声学交互试验 Dock**：支持主动一键手动切换“隔壁房间”虚掩门低通衰减试听、一键触发纯物理算法合成的晶莹水滴声并在示波器上激荡扩散涟漪；
  - **视听微波联觉**：Web Audio `AnalyserNode` 实时提取声音能量，平滑驱动顶部指示波纹的起伏幅度。

## 🚢 部署与环境变量配置

本项目完全适配 **Cloudflare Pages**，全球 Anycast CDN 边缘极速直连。

### 1. 命令行一键部署
```bash
# 设置 Cloudflare 凭证
export CLOUDFLARE_API_TOKEN="your-cloudflare-api-token"
export CLOUDFLARE_ACCOUNT_ID="your-cloudflare-account-id"
```

### 2. 环境变量 (Cloudflare Secrets)
在 Cloudflare Pages 项目后台 `Settings` → `Variables and Secrets` 中配置以下密钥：

| 变量名 | 必填 | 说明 |
| :--- | :---: | :--- |
| `DEEPSEEK_API_KEY` | **是** | DeepSeek 官方 API 密钥（驱动对话、原生看图多模态与联网搜索） |
| `GEMINI_API_KEY` | 选填 | Google AI Studio 密钥（驱动 Gemini 模型切换） |
| `CHAT_ADMIN_KEY` | 选填 | 对话窗口解锁无限制长篇模式的管理密码 |
| `ZHANGYA_MODEL` | 选填 | AI 写作助手专属模型覆盖（默认 fallback 为 `deepseek-flash`） |
